Current situation

Where it hurts today

Near-term pains are different from the long-term mass-recruitment end-game.

Near-term

Hard to find candidates

  • Scarcity for junior airport catering roles
  • Not mainly “too many applications to process”
  • Need better capture + reactivation when people appear
Near-term

After-hire connecting is tedious

  • Reminders, day-1 pings, chase when quiet
  • Live rescue when someone is lost still needs a human
  • Platform can automate the planned messages

End-game (agreed)

For true mass recruitment later, SleekFlow / an AI messaging agent is the destination — shared inbox, flows, stages, proactive templates, ad capture.

Options

Three paths

Option A

Keep current process

  • No new tool cost
  • No learning toward end-game
  • Same manual chase forever
Option B

WhatsApp Business only

  • Greeting / OOO / quick replies
  • Low cost interim
  • Does not build the AI / mass path
  • Weak multi-agent inbox
Option C

SleekFlow short pilot

  • Contract can be 1–4 months (not forced yearly)
  • ~20k/year level pricing → pro-rate for pilot
  • Starts the agreed end-game stack
  • Meta template fees extra for outreach

Recommendation

What I believe makes most sense

Option C — start a short SleekFlow pilot (1–4 months)

End-game is already agreed (SleekFlow / AI for mass recruitment). A short contract lets us build the real stack now, learn on our SOP, and avoid a full-year lock before value is proven.

Pilot scope

  • Apply intake + contact stages
  • Interview / test / day-1 reminder templates
  • Shared inbox for People / Ops
  • Optional: reactivate past applicants

Success criteria (before renew)

  • Less retyping on apply / chase
  • Fewer missed day-1 no-shows from silence
  • Team can run inbox without phone chaos
  • Clear view of Meta template cost vs benefit

# APAC Christmas Lunch — Back to School Edition

Standalone HTML presentation for the APAC Christmas Lunch (Class of 2026), matching the festive Tailwind look & feel from the finalized party deck.

## Open

Open `apac-christmas-lunch.html` in Chrome / Edge / Firefox, or serve locally:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8080/apac-christmas-lunch.html`.

## Look & feel

- Plus Jakarta Sans + Fredoka + Caveat
- Festive palette: red `#C8372D`, pine `#1E6B3B`, slate blue `#23486A`, gold `#D97724`, ice blue accents
- Lined `festive-card` panels, wood-framed `chalkboard-card` boards
- Snow canvas, bunting SVG décor, auto-hiding stage HUD

## 18 slides

2. Meet Your MCs (Maruko & Hanawa walk-outs)  
3. Headmaster Dumbledore curtain reveal  
4. Lunch buffet preview  
5–6. Game 1 Quick Guess + AhaSlides launcher  
7–11. Cooking Challenge (intro, roles, workflow, 6-set menu uploads, timer + webcam/VDO.ninja)  
12. Tuck Shop recess  
13–14. Lucky Draw Phase 1 spinner + report card / prize photos  
15. Best Dressed award  
16–17. Phase 2 grand finale intro + honor roll / prize photos  
18. Group photo graduation backdrop  

## Interactive tools

- **StudioSynth** Web Audio BGM with continuous tracks across related slides  
- Custom slide MP3 + school bell uploads  
- Honor Roll spinner (Phase 1 / Phase 2), shuffle, A–Z, auto-eliminate, batch draw, confetti  
- **Save HTML** bakes roster, photos, audio, and customizations into a standalone file  

## Controls

| Control | Action |
|---|---|
| ← → | Previous / next slide |
| Space (on spinner) | Spin |
| Hover bottom edge | Reveal stage HUD |
| Save HTML | Export baked presentation |

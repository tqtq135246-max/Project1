# APAC Christmas Lunch — Back to School Edition

Standalone HTML presentation for the APAC Christmas Lunch (Class of 2026), matching the festive Tailwind look & feel from the finalized party deck.

## Open

Open `apac-christmas-lunch.html` in Chrome / Edge / Firefox, or serve locally:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8080/apac-christmas-lunch.html`.

## Look & feel

- Plus Jakarta Sans + Fredoka + Caveat
- Festive palette: red `#C8372D`, pine `#1E6B3B`, slate blue `#23486A`, gold `#D97724`, ice blue accents
- Lined `festive-card` panels, wood-framed `chalkboard-card` boards
- Snow canvas, bunting SVG décor, auto-hiding stage HUD

## Interactive tools

- **Phase BGM**: upload an MP3 per phase (Opening / Games / Recess / Christmas Gifts / Best Dressed / Grand Prizes / Finale). Play once — music continues as slides flow within that phase  
- Company **logo** upload in the toolbar (shows top-left)  
- School bell MP3 upload  
- **Christmas Gifts** spinner: batch sequence 3 → 3 → 4 → 3 → 1  
- **Grand Prizes** spinner: ranks #1–#6, one winner each  
- Floor livestream: VDO.ninja room + **phone QR** to broadcast  
- **Save HTML** bakes roster, photos, audio, logo, and customizations  

## Controls

| Control | Action |
|---|---|
| ← → | Previous / next slide |
| Space (on spinner) | Spin |
| Hover bottom edge | Reveal stage HUD (hidden otherwise) |
| Logo | Upload company logo |
| Phase MP3 | Upload BGM for the selected phase |
| Save HTML | Export baked presentation |

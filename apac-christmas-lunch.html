Order Flow • 流程指引

GAME WORKFLOW • 遊戲運作流程

Step 1
Floor orders + order forms
  • Order takers take orders from the floor
  • Every table uses an order form (sample on next slide)
  • Rotation: Team A → B, B → C, C → A
Step 2
Tell the Chef
  • Order Taker speaks the order to Chef
  • No silent pointing — verbal only
Step 3
Assemble from food pool
  • Chef builds the meal to match the order
  • Pass the finished plate to Server
Step 4–5
Serve + head-table exam
  • Server delivers meal + order form together
  • Head table checks if the order is correct
  • Fastest correct team wins
